# ============================================================================
# 原创曲，不是《春日影》。E 大调，4/4，24 小节，约 76 秒。
#
# 音阶对照（E 大调）：
#   低音区  E3=a  F#3=d  G#3=g  A3=h  B3=k  C#4=;  D#4=Enter
#   中高音区 E4=q  F#4=e  G#4=t  A4=y  B4=i  C#5=p  D#5=]  E5=1
#   高音区   F#5=3  G#5=5
#
# 和弦（左手，全部在低音区）：
#   E    = a g k        (E3 G#3 B3)
#   B    = k Enter e    (B3 D#4 F#4)
#   C#m  = ; q t        (C#4 E4 G#4)
#   A    = h ; q        (A3 C#4 E4)
#   G#m  = g k Enter    (G#3 B3 D#4)
#   F#m  = d h ;        (F#3 A3 C#4)
#
# 结构：前奏 4 小节 → A 段 8 小节 → B 段（副歌）8 小节 → 尾声 4 小节
# ============================================================================
